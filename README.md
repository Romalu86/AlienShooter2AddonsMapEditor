# Alien Shooter 2 Map Editor

Alien Shooter 2 Map Editor is a Win32/x86 reconstruction of the original AS2 Addons map editor, prepared for Visual Studio 2022 while preserving the established editor behavior, file formats, rendering paths, scripting, map logic and legacy runtime compatibility.

This branch targets **Alien Shooter 2 - Reloaded \ Conscription \ Zombie Shooter 2 Teaser**.

## Build target

- Visual Studio 2022
- Platform toolset: v143
- Platform: Win32 / x86
- Recommended configuration: Release
- Runtime library: static CRT (`/MT` in Release)
- C++ language mode: C++14

Open `MapEdit.sln`, select `Release | Win32`, and build the `MapEdit` project. The executable is written to `bin/Release/MapEdit.exe`.

DirectX headers and `d3dx9.lib` are stored under `third_party/directx9`. Ogg/Vorbis sources are included under `third_party/libogg` and `third_party/libvorbis` and compiled with the project. The build does not download external packages.

## Runtime data

The executable expects the normal **Alien Shooter 2 - Reloaded \ Conscription \ Zombie Shooter 2 Teaser** editor/game data in its working directory, including `MapEdit.cfg`, game resources and `QuestEditor.dll`.

Game resources and `QuestEditor.dll` are not generated by the build. Use the files from a compatible Alien Shooter 2 Gold installation/editor setup.

## Source layout

- `src` — application startup, editor UI, maps, rendering, audio, resources, scripting and runtime logic
- `resources` — Windows resources
- `runtime` — starter configuration and empty map
- `third_party/directx9` — local DirectX headers and D3DX library
- `third_party/libogg`, `third_party/libvorbis` — Ogg/Vorbis sources
- `MapEdit.sln`, `MapEdit.vcxproj` — Visual Studio 2022 solution and project

## Required runtime files

A starter `MapEdit.cfg` and `Maps/new.map` are included under `runtime`. To use the starter setup, copy `runtime/MapEdit.cfg` and the `runtime/Maps` directory to the editor's working directory.
